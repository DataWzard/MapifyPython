# Privacy

PyMap does not create accounts, collect form submissions, run analytics, set cookies, or send inspected Python source code to a PyMap server. Files selected in the application remain in the visitor's browser.

The browser downloads Pyodide and D3 from jsDelivr. Like ordinary web hosting and CDN providers, GitHub Pages and jsDelivr may receive standard request information such as an IP address, browser user agent, requested URL, and timestamp under their own policies.

Because PyMap does not use cookies or similar tracking technologies, it does not display a cookie-consent banner. If analytics, advertising, authentication, persistent browser storage, or other tracking is added later, this notice and the consent decision must be reviewed before deployment.
